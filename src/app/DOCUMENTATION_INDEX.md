## 📞 When You Need Help

### Checklist Before Asking

- [ ] Checked relevant documentation?
- [ ] Tried [CAMERA_TROUBLESHOOTING.md](./CAMERA_TROUBLESHOOTING.md)?
- [ ] Checked browser console (F12)?
- [ ] Verified same WiFi (mobile)?
- [ ] Tried different browser?
- [ ] Restarted computer?

### Information to Provide

When reporting issues, include:

**Environment**:
- OS: (Windows 11, macOS 14, Ubuntu 22.04, etc.)
- Browser: (Chrome 120, Safari 17, etc.)
- Node version: `node --version`
- Device: (Desktop, iPhone 14, Samsung S23, etc.)

**Error Details**:
- Error message: (exact text)
- Console output: (F12 → Console tab)
- Steps to reproduce: (what you did)

**What You've Tried**:
- [ ] Browser permissions
- [ ] System permissions  
- [ ] HTTPS setup
- [ ] Firewall configuration
- [ ] Different browser
- [ ] Restart computer
